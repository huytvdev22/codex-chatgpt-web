# 101: Tích hợp Adapter Gemini Web (`gemini`) theo kiến trúc đa provider + Sign in with Chrome

> **Trạng thái:** ⏳ Chờ User Test & Confirm  
> **Providers:** `gemini`, `web`, `launcher`, `electron`, `chrome-login`, `profiles`  
> **Keywords:** `GeminiAdapter`, `GeminiModelProvider`, `GeminiBrowserWorker`, `GeminiCapabilityPicker`, `GeminiModelDiscovery`, `GeminiBrowserProvider`, `SignOutOptions`, `bard-mode-menu-button`, `thinking_level`, `ql-editor`

## ⚡ TL;DR
1. **Triệu chứng:** Repo chưa có adapter `gemini` (`gemini.google.com`) trong `ModelRegistry` / `AdapterRegistry` / `BrowserProviderRegistry`; quá trình tích hợp gặp 4 cạm bẫy DOM/auth đặc thù: nút Google Account sau đăng nhập chứa `href="https://accounts.google.com/SignOutOptions"` làm `probeAuthentication` nhận nhầm là nút Sign in, submenu `Thinking level` nằm lồng trong `gem-mode-menu`, `execCommand("insertText")` trên Quill editor (`.ql-editor`) cắt mất nội dung sau ký tự `\n` đầu tiên, và `ModelConfigStore` cần đồng bộ offline fallback trong `models-store.cjs`.
2. **Nguyên nhân gốc rễ:** Thiếu provider `gemini` tách riêng partition/đa profile, chưa có bộ driver DOM kiểm chứng trực tiếp trên `gemini.google.com` (`bard-mode-menu-button`, `gem-menu-item[role="menuitemradio"]`, `thinking-overlay`, `code-block`, `Turn on temporary chat`), và `execCommand("insertText")` không xử lý chuỗi đa dòng trên Quill editor của Angular `rich-textarea`.
3. **Cách sửa:** Triển khai trọn bộ `src/adapters/gemini/` (`GeminiModelProvider` 1M context / 900K auto-compact, `GeminiBrowserWorker` dùng `.fill()` + fallback DOM `<p>` cho Quill editor, `GeminiCapabilityPicker` hỗ trợ Mode Picker + `Thinking level` submenu + `Temporary Chat` cho lượt `retain: false`, `GeminiAttachments` tối đa 3 ảnh, `GeminiDomObserver` loại bỏ `thinking-overlay`/`model-thoughts`/`.code-block-decoration`, `GeminiClipboardSalvage`, `GeminiModelDiscovery` lọc đúng cấp top-level `gem-mode-menu`), đăng ký `GeminiBrowserProvider` (`persist:codex-web-gemini[-pN]`, loại trừ `SignOutOptions` khi probe auth) và mở rộng `chrome-session-extractor.ts` cho `gemini`.
