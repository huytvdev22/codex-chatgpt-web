# 097: Tích hợp Adapter ChatGPT Web (`chatgpt`) theo kiến trúc đa provider + Sign in with Chrome

> **Trạng thái:** ✅ Đã Confirm
> **Providers:** `chatgpt`, `web`, `launcher`, `electron`, `chrome-login`, `profiles`  
> **Keywords:** `ChatGptAdapter`, `ChatGptModelProvider`, `ChatGptBrowserWorker`, `ChatGptCapabilityPicker`, `ChatGptBrowserProvider`, `supportsExternalChromeLogin`, `__Secure-next-auth.session-token`, `data-talvt-turn-state`, `data-selected-reasoning-effort`

## ⚡ TL;DR
1. **Triệu chứng:** Repo sau refactor v6.12.x chỉ còn `m365-copilot` và `ai-studio`; luồng đăng nhập qua Chrome thật (`ExternalChromeLoginService` + `chrome-session-extractor.ts`) và UI Electron Launcher bị hardcode riêng cho `ai-studio`.
2. **Nguyên nhân gốc rễ:** Thiếu adapter `chatgpt` trong `ModelRegistry` / `AdapterRegistry` / `BrowserProviderRegistry`, đồng thời cơ chế chọn model/reasoning mới trên `chatgpt.com` dùng popover `Select ChatGPT model` (`data-reasoning-slider`, `data-model-picker-view-toggle`) và chunked NextAuth cookie (`__Secure-next-auth.session-token.0`/`.1`).
3. **Cách sửa:** Tổng quát hóa `Sign in with Chrome` theo provider (`supportsExternalChromeLogin`, `hasExternalAuthSessionCookies`, `--provider`), triển khai trọn bộ `src/adapters/chatgpt/` (`chatgpt/gpt-6.2`, `chatgpt/gpt-6`, `chatgpt/gpt-5.6-sol` kèm Model/Thinking picker, đính kèm tối đa 3 ảnh, plain-text ProseMirror injection, clipboard salvage + DOM observer theo `[data-talvt-turn-state]`), và đăng ký `ChatGptBrowserProvider` hỗ trợ đa profile `persist:codex-web-chatgpt[-pN]` trên Launcher.
